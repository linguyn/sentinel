## What I learned

- A target position is an absolute world coordinate, while movement requires a direction calculated using `targetPosition - playerPosition`.
- Normalizing a direction separates movement direction from movement speed.
- `transform.position` refers to the GameObject containing the script, so the correct player `Transform` must be referenced when the script is on another object.
- An AI action should have a lifecycle: receive → execute → complete → consume.
- `ApiClients` should handle backend communication, while `AIIntent` should determine when an in-game action has completed.
- Action completion and action success are different concepts.

## Problems

- Initially used the `AIIntent` GameObject's transform instead of the player's transform, causing the distance-to-target calculation to be incorrect.
- The backend response could continue being read after the action had completed, so the completed `ActionResponse` needed to be cleared.
- Needed to use a distance tolerance instead of checking for an exact target position because movement uses floating-point values.
